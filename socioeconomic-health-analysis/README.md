# Socioeconomic Predictors of Self-Reported Health

## Overview
Examines how demographic, socioeconomic, and healthcare access variables influence self-reported overall health using CDC BRFSS data.

## Dataset
CDC Behavioral Risk Factor Surveillance System (BRFSS) public survey data.

## Methods
- Data cleaning  
- Correlation analysis  
- Multiple linear regression modeling in Python  

## Key Findings
- Employment, income, cost barriers, and disability status significantly predict health outcomes.  
- Model explains 29.3% of variance in self-reported health.

## Key Takeaways
- **Income vs. health scores:** shows strong positive relationship  
- **Employment status distribution:** highlights gaps in reported health outcomes  

## Tools
Python, Jupyter Notebook
