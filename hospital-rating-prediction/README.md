# Predicting Hospital Ratings Using CMS Data

## Overview
Predicts overall hospital quality ratings using demographic and performance data from the Centers for Medicare & Medicaid Services (CMS).

## Dataset
Historical CMS hospital quality data including ownership, location, mortality measures, and EHR-related variables.

## Methods
- Data cleaning  
- Correlation analysis  
- Multiple regression modeling  
- Permutation testing  
- Cross-validation in R  

## Key Findings
- Hospital ownership, mortality indicators, and selected operational characteristics influence ratings.  
- Identified key predictors that could inform quality improvement efforts.

## Key Takeaways
- **Mortality vs. hospital rating scatter plot:** shows clear negative correlation  
- **Ownership type distribution:** highlights patterns in quality ratings across private vs. public hospitals  

## Tools
R, Jupyter Notebook
