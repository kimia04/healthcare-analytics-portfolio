# Healthcare Analytics Portfolio

This repository contains selected academic projects applying data analysis, statistical modeling, and visualization to healthcare spending, hospital quality, and population health questions.

## Featured Projects

1. [Healthcare Spending Trends in the U.S. (1996–2016)](./healthcare-spending-trends-us)  
2. [Socioeconomic Predictors of Self-Reported Health](./socioeconomic-health-analysis)  
3. [Predicting Hospital Ratings Using CMS Data](./hospital-rating-prediction)

Each project folder contains:
- A cleaned Jupyter notebook or R notebook with analysis
- A PDF report (or notebook-exported report)
